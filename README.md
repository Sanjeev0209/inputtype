# Interactive Form Showcase (inputtype)

A modern, responsive showcase displaying HTML5 input types with ambient background styling, validation, and interactive controls.

## Features
- Complete collection of HTML5 input types
- Clean, modern UI with responsive design
- Ambient floating background effects
- Form state handling via JavaScript

## Files
- `index.html` - Form structure and input elements
- `style.css` - Custom styling and responsive design
- `script.js` - Form validation and submission logic
